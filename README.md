# Пять элементов — запись на мероприятия

Прототип сервиса регистрации на экскурсии и мероприятия ЖК «Пять элементов».

## Посмотреть

- Запись: https://ilya260.github.io/five-elements-events/
- Конструктор: https://ilya260.github.io/five-elements-events/builder.html

Демо опубликовано через GitHub Pages. Его можно открыть по ссылке без входа в аккаунт.

## Возможности

- Адаптивная схема с платными и бесплатными местами.
- Регистрация по имени и телефону без личного кабинета.
- Отдельный шаг оплаты для платных мест.
- Конструктор мероприятий: описание, дата, время, ряды, цены, блокировки и проходы.
- Предпросмотр созданного мероприятия и импорт/экспорт JSON.

## Запуск

Нужен Node.js 18 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Откройте http://localhost:3000/ и http://localhost:3000/builder.html.

Файлы можно разместить на любом статическом хостинге, включая GitHub Pages. В настройках Pages выберите ветку main и корневую папку репозитория.

## Текущее состояние

Это прототип для согласования интерфейса. Мероприятия, черновики и записи хранятся в localStorage конкретного браузера. Ссылка предпросмотра созданного события работает в том браузере, где оно сохранено. Для переноса используйте экспорт и импорт JSON.

Общая база данных, серверное резервирование мест, доступ администратора, уведомления и платёжный провайдер пока не подключены. Успешная оплата не имитируется. Юридические документы — заглушки.

## Состав

- index.html, app.js, style.css — страница записи.
- builder.html, builder.js, builder.css — конструктор.
- event-loader.js — загрузка локального предпросмотра мероприятия.
- assets/ — логотип, графика и шрифтовые стили.
- legal/ — заглушки документов.
